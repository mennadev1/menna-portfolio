MENNA ALI — FRONTEND PORTFOLIO

HOW TO RUN
1. Extract the ZIP file.
2. Open the menna-portfolio folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.

HOW TO ADD YOUR PHOTO
1. Put your photo in the same folder as index.html.
2. Rename the image to: my-photo.jpg
3. Refresh the page.

HOW TO PERSONALIZE
- In index.html, change the example email menna@example.com to your email.
- Replace the # links for GitHub, LinkedIn, Live preview, and Source code with your real links.
- Update the text to match your actual skills and projects.
- The project preview illustrations are made with HTML/CSS; replace the # project links with your own deployed project and GitHub repository.
- If you don't have a CV ready, remove or add a CV link later as needed.

FILES
index.html — page content
style.css — design, colors, responsive layout
script.js — mobile navigation and scroll reveal effects
